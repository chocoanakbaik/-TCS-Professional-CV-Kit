# TCS Account Registration

Repository ini disiapkan sebagai basis pengembangan sistem pendaftaran akun untuk ekosistem **The Choco Studios (TCS)**. Nama repository `-TCS-Professional-CV-Kit` merupakan slug historis yang tidak menggambarkan fungsi repository saat ini.

## Tujuan

Menjadi lokasi dokumentasi dan pengembangan sistem pendaftaran akun pengguna TCS. Repository ini bukan produk CV kit dan tidak boleh dipasarkan atau dideskripsikan sebagai generator resume.

## Status implementasi

**Tahap persiapan dokumentasi.** Repository saat ini hanya berisi dokumentasi awal. Sistem pendaftaran, autentikasi, database, API, dan konfigurasi deployment belum diimplementasikan di repository ini.

Jangan menganggap keberadaan repository ini sebagai bukti bahwa sistem TCS Account sudah dibangun di sini. Integrasi akun yang sudah berjalan pada aplikasi TCS dapat menggunakan layanan pusat atau repository lain.

## Catatan keamanan

- Jangan menyimpan kata sandi, token akses, private key, atau kredensial aktif di repository.
- Data pribadi pengguna hanya boleh diproses dan disimpan melalui layanan yang memang disiapkan untuk kebutuhan tersebut.
- Setiap implementasi autentikasi harus menggunakan praktik keamanan yang sesuai, termasuk penyimpanan kata sandi dalam bentuk hash yang aman.
- Jangan mengubah alur autentikasi yang sudah berjalan pada aplikasi lain tanpa audit dan persetujuan terpisah.
